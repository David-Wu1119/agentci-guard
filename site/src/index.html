        05 / KNOW THE BOUNDARY

        Useful signals.
        Explicit limits.

        Use Guard alongside source review and runtime controls. A supported clean scan is not proof of security.

        Possible paths, not exploits

        Severity reflects review priority over supported static semantics. It does not prove an attacker can execute a path.

        Coverage has edges

        Dynamic expressions, scripts, tool-driven fetches and remote reusable workflows can exceed the model. Even a complete scan can miss an unmodeled path.

        Accuracy is unmeasured

        The 152 fixed development snapshots let readers rerun scanner behavior; they do not establish accuracy. Sealed human-labeled evaluation and measured precision/recall are not established.

        Version matters

        The fixture and expected results are pinned to a public commit; this page's browser scanner is a separate build. Compare versions before treating a mismatch as a regression.
